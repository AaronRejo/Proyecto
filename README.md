# Proyecto Basketball Fantasy

## Contexto

El básquetbol es uno de los deportes más populares del mundo y se caracteriza por la importancia que tienen las estadísticas para analizar el rendimiento de diferentes jugadores y equipos. Durante un partido se pueden registrar diferentes datos, como puntos anotados, rebotes, asistencias, robos, bloqueos y pérdidas de balón. Estas estadísticas ayudan a determinar el rendimiento de jugadores y como influyeron en un equipo.

Con estas estadísticas se creo el juego de Basketball Fantasy, en donde los participantes pueden crear equipos virtuales utilizando jugadores reales. En este tipo de juegos, los jugadores debe tomar decisiones de la estructura de su equipo, ya que están limitados a un presupuesto. El objetivo es formar el equipo que consiga la mayor cantidad de puntos dependiendo del rendimiento de los jugadores. 

El proyecto de Basketball Fantasy va a consistir en crear un programa que simule este tipo de juego utilizando estadísticas de jugadores de la temporada 2025 - 2026. El usuario tendrá un presupuesto determinado y dentro va a seleccionar jugadores de una lista para formar su propio equipo. Estos jugadores tendrán diferentes precios dependiendo de sus características. Al estar creando partidos que van a estar simulados donde estas estadísticas se van a estar sacando, y al finalizar estas estadísticas se van a sumar para el equipo en donde están. El usuario no va a competir contra personas reales, sino con el programa donde tendrá diferentes equipos. Con todas estas estadísticas se va a buscar quien es el que mayor puntuación obtuvo en el que se le nombrara el ganador de esa temporada.

## Pseudoalgoritmo

1. Inicio
2. Seleccionar nombre de equipo
3. Selección de jugadores
4. Simular partidos entre equipos en base a datos de jugadores (Repetir lo siguiente durante 4 partidos)
      1. Datos:
            - Puntos
            - Rebotes
            - Robos
            - Perdida de Balón
            - Asistencias
            - Faltas
            - Bloqueos  
     2. Presentar estadísticas de los partidos
     3. El equipo con mayor puntaje se mostrara como ganador del partido

6. Hacer el partido final entre el primero y el segundo lugar
7. El ganador de ese partido se declarara como el campeón del torneo
8. Fin
